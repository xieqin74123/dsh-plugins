# DSH 会话通知插件

> ⚠️ 代码由 DSH 生成，未经人工审核；使用前请自行审查。见[仓库说明](../../README.md)。

在 DeepSeek Harness Web UI 中，为**当前会话**推送桌面（系统）通知：一轮回复结束时提醒「回复已就绪」，Agent 通过 `ask_user_question` 提问或请求工具批复时提醒「请求回答 / 请求批复」。输入框右下角有一个铃铛小图标，亮起表示本会话启用通知（默认），点暗即关闭。

## 功能

- **轮次结束通知**：会话的 Agent 从 running 变为空闲时，推送一条通知。
  - 标题固定为 `Deepseek Harness`。
  - 正文为 `[会话名称]：回复已就绪`（会话名称取侧边栏显示的标题，过长会截断）。
- **等待用户输入通知**：Agent 发布待处理交互时立即推送：
  - `ask_user_question` 普通提问 → `[会话名称]：请求回答`
  - plan review（计划确认） → `[会话名称]：请求确认计划`
  - 工具权限批复 → `[会话名称]：请求批复`
  - 其它未知交互 → `[会话名称]：需要你的操作`
- **只在用户不在当前会话时推送**（可由浏览器判断的部分全部实现）：
  - 浏览器标签页隐藏（`document.visibilityState !== 'visible'`）；
  - 浏览器窗口没有焦点（`document.hasFocus() === false`）；
  - 当前主视图打开的是设置、插件等全局面板（`layout.panelInfo.activePanelId !== null`）；
  - 当前主视图选中的是另一个会话。
  
  以上任一条成立即推送；用户正看着当前会话时不打扰。若提问出现时用户还在看当前会话、随后才切走（失焦、切标签页、切换会话、打开全局面板），会在注意力变化时补发一次，已经发过的不重复。
- **单图标开关**：输入框右下角、模型选择器左侧的铃铛。
  - 实心 + 主题色 = 本会话启用通知；
  - 空心 + 灰色 = 本会话关闭通知；
  - 右上角小圆点 = 已启用但还不能真正送达：
    - 琥珀色：浏览器尚未授权（页面内第一次非铃铛点击/按键会自动弹出一次授权请求；把铃铛关掉再打开也会重新请求）；
    - 红色：浏览器已阻止通知，需要在站点设置中允许。
  - 默认启用。开关状态按会话 id 存在 `localStorage`（`dsh.session-notify.disabled.v1`），刷新、重连、重启后保持。
- **点击通知**：聚焦窗口并切换到对应会话；请求被回答或撤回后，指向它的常驻通知会自动关闭。
- **多标签页**：相同通知使用同一个 `tag`，操作系统层面会替换而不是叠出多条。
- **子代理 / 后台会话**：目录里可见的会话（包括后台运行的定时任务会话）都会通知；`origin: subagent` 且不在主视图中的子代理会话会被静默，避免多代理工作流刷屏。不在会话目录中的 id 不通知（无法命名，也无法从通知打开）。

## 实现

纯浏览器插件，没有宿主服务：

- `index.js`：空的宿主半边，只为让 bundle 在 Loader 中拥有一行，从而把 `dsh.client` 暴露的浏览器 bundle 纳入 Web 模块图。
- `client.js`：注册 `conversation.input.right` 槽位（铃铛），并订阅 `ctx.uiSession.sessionStatus`：
  - `running` 从 `true` 变为 `false` 且没有待处理交互 → 轮次完成；
  - `pendingInteraction` 出现或 `key` 变化 → Agent 等待用户；
  - 窗口失焦/隐藏、切换会话或打开全局面板时，重新扫描仍待处理的交互，补发用户离开前没看到的提问。
- 通知使用浏览器 `Notification` API（在桌面浏览器和 Electron 桌面上就是系统通知），权限在用户第一次交互时请求一次；如果被忽略，点击铃铛再次启用时会重试。
- 判断「是否在看当前会话」使用主视图的 `mainView` 引用计数和布局面板状态，与 DSH 自带的未读提示规则一致。

## 安装

本插件是 [dsh-plugins](../../README.md) 里的一个 DSH bundle。在 DSH Web 侧边栏打开 **Plugins → 添加插件**，把下面这一行粘贴到输入框：

```text
https://github.com/xieqin74123/dsh-plugins#path:/packages/dsh-session-notify
```

`#path:` 是 pnpm 的 Git 子目录参数，DSH 的安装器会把整条 spec 交给 pnpm，所以一个仓库可以放多个插件。也可以先把仓库克隆到本地，在同一个输入框里填本目录的绝对路径（必须是绝对路径，例如 `/home/you/dsh-plugins/packages/dsh-session-notify`）。安装后 bundle 默认启用；如果页面没有自动重载，刷新页面或重启 `dsh web`。完整说明见[仓库根 README](../../README.md)。


## 已知边界

- 通知依赖页面存活；浏览器完全冻结后台标签页（Chrome 的内存节省模式）后，页面收不到状态事件，通知会延迟到页面恢复。没有常驻 Service Worker 也能在普通后台标签页工作。
- 权限只能由用户手势触发；首次进入页面后第一次点击或按键时会弹出一次授权请求（点击铃铛本身除外：它先完成开关切换，只有从关到开时才请求）。若用户忽略，铃铛上的琥珀点会保留提示，关闭再开启可重试。
- 通知内容跟随 UI 语言（中文界面为中文，英文界面为英文）；标题始终是 `Deepseek Harness`。
- 只支持 Web/Electron 桌面端；headless/CLI 没有 `Notification`，插件会安全地退化为不显示。
